# Kingdom Coffee

A visually rich coffee shop landing page designed to showcase drinks, products, and brand personality.

## Project Concept

The site presents a café experience through a warm visual identity, product imagery, navigation, and content sections that introduce visitors to a coffee brand and its menu.

## Highlights

- Coffee-focused landing page
- Product and drink presentation
- Responsive navigation
- Rich image-based sections
- Custom typography and icons
- Responsive CSS layout

## Tech Stack

- HTML5
- CSS3
- Font Awesome
- Google Fonts

## Run Locally

```bash
git clone https://github.com/AbdUlkaderAlmalky/coffee-store.git
cd coffee-store
```

Open:

```text
kingdom coffe/index.html
```

## Purpose

A frontend design project focused on branding, visual hierarchy, responsive layout, and product presentation for a coffee business.
